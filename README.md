# Voltify Africa website

A responsive static website built with plain HTML, CSS and JavaScript. It has no package dependencies or backend.

## Preview

Serve this folder with any static web server and open its local URL. For example, from PowerShell:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Product and data assumptions

- The Voltify Connect product rendering and its internal assembly view are conceptual visual studies. They do not represent verified dimensions, a confirmed connector type or pinout, a PCB layout, electrical architecture, protocol, or connectivity design.
- Voltify Connect is described for compatible meters with supported interfaces. No universal meter compatibility is claimed.
- Dashboard values and planned capability examples are simulated. The site has no live meter feed, customer records, or backend.
- The contact action opens an email draft without a recipient because an official contact address was not included in the supplied brief.
